# 阅读交互

资讯与文章共用 `ArticleReadingNav`：桌面侧栏整合目录、当前章节高亮、阅读进度和上一条、下一条、返回阅读、顶部操作，正文下方不再悬浮工具卡片。窄屏只显示右下角 44px 目录入口，点击后展开目录及操作面板；选中章节后收起。目录面板支持 Escape 关闭与键盘操作；系统启用减少动态效果时禁用平滑滚动。

资讯保留正文前的前 20 条目录与稳定的 `item-featured-*` 锚点。原文在新标签页打开，并使用 `noopener noreferrer`。其余资讯依然默认折叠为标题列表。

`useReadingHistory` 在浏览器返回／前进和刷新时恢复本标签页的滚动与 details 展开状态。异步正文未加载时等待内容就绪，用户主动滚动可中止恢复；存储不可用时退化为普通导航。显式新页面导航从顶部开始，带片段的直达链接定位章节。文章／资讯页的返回按钮在没有站内历史时使用列表／首页作为后备。

资讯列表和正文使用 30 秒内存缓存，失败不缓存，重试强制刷新。历史日期列表翻页不替换正在阅读的正文。写作页按需加载，公共阅读页不再预加载编辑器入口。

本地验证：496 项测试通过，TypeScript 与生产构建通过；真实页面检查了桌面目录、手机面板、锚点与返回位置、外链属性、浏览器返回和个人文章列表往返。原有大型 JS bundle 警告仍存在，未声称完成整个应用的加载性能优化。
